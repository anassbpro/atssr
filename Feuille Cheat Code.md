# Feuille Cheat Code Windows

> Toutes les commandes `.cpl`, `.msc` et « Exécuter » s'ouvrent avec **Windows + R**, puis Entrée.

---

| Commande | Ouvre |
|---|---|

| `firewall.cpl` | Pare-feu Windows Defender |
| `hdwwiz.cpl` | Ajout de matériel |
| `inetcpl.cpl` | Options Internet (proxy, sécurité) |
| `intl.cpl` | Région (formats de date, heure, nombres) |
| `joy.cpl` | Contrôleurs de jeu (manettes) |
| `main.cpl` | Souris |
| `mmsys.cpl` | Son (périphériques audio) |
| `ncpa.cpl` | Connexions réseau (cartes, IP) |
| `powercfg.cpl` | Options d'alimentation |
| `sysdm.cpl` | Propriétés système (nom du PC, variables d'environnement, restauration) |
| `tabletpc.cpl` | Stylet et fonctions tactiles |
| `timedate.cpl` | Date et heure |
| `wscui.cpl` | Sécurité et maintenance |

## 4. Raccourcis touche Windows (⊞)

### Système et navigation
| Raccourci | Action |
|---|---|
| `Win` | Menu Démarrer |
| `Win + R` | Exécuter |
| `Win + S` / `Win + Q` | Recherche |
| `Win + E` | Explorateur de fichiers |
| `Win + I` | Paramètres |
| `Win + X` | Menu rapide (Terminal, Gestionnaire de périphériques…) |
| `Win + L` | Verrouiller la session |
| `Win + D` | Afficher / masquer le bureau |
| `Win + ,` | Aperçu rapide du bureau |
| `Win + A` | Paramètres rapides (Wi-Fi, son…) |
| `Win + N` | Notifications et calendrier |
| `Win + W` | Widgets |
| `Win + V` | Historique du presse-papiers |
| `Win + .` | Emojis et symboles |
| `Win + H` | Dictée vocale |
| `Win + U` | Accessibilité |
| `Win + Pause` | Infos système |

### Fenêtres
| Raccourci | Action |
|---|---|
| `Win + ↑` | Agrandir la fenêtre |
| `Win + ↓` | Réduire / restaurer |
| `Win + ←` / `→` | Ancrer à gauche / à droite |
| `Win + Z` | Dispositions d'ancrage |
| `Win + M` | Réduire toutes les fenêtres |
| `Win + Shift + M` | Restaurer les fenêtres réduites |
| `Win + Home` | Réduire toutes sauf la fenêtre active |
| `Win + Shift + ←` / `→` | Déplacer la fenêtre vers l'autre écran |
| `Win + 1…9` | Ouvrir l'appli n° de la barre des tâches |
| `Win + T` | Parcourir la barre des tâches |

### Bureaux virtuels
| Raccourci | Action |
|---|---|
| `Win + Tab` | Vue des tâches |
| `Win + Ctrl + D` | Nouveau bureau virtuel |
| `Win + Ctrl + ←` / `→` | Changer de bureau |
| `Win + Ctrl + F4` | Fermer le bureau actuel |

### Captures et écrans
| Raccourci | Action |
|---|---|
| `Win + Shift + S` | Capture d'une zone (Outil Capture) |
| `Win + Impr. écran` | Capture plein écran enregistrée dans Images |
| `Win + G` | Game Bar |
| `Win + Alt + R` | Enregistrer l'écran (Game Bar) |
| `Win + P` | Mode de projection (dupliquer, étendre…) |
| `Win + K` | Caster vers un écran sans fil |
| `Win + +` / `Win + Échap` | Loupe (ouvrir / fermer) |
| `Win + Ctrl + Shift + B` | Relancer le pilote graphique (écran noir) |

## 5. Raccourcis Ctrl

### Édition (partout)
| Raccourci | Action |
|---|---|
| `Ctrl + C` | Copier |
| `Ctrl + X` | Couper |
| `Ctrl + V` | Coller |
| `Ctrl + Shift + V` | Coller sans mise en forme (selon l'appli) |
| `Ctrl + Z` | Annuler |
| `Ctrl + Y` | Rétablir |
| `Ctrl + A` | Tout sélectionner |
| `Ctrl + S` | Enregistrer |
| `Ctrl + P` | Imprimer |
| `Ctrl + F` | Rechercher |
| `Ctrl + H` | Rechercher et remplacer (Word, éditeurs) |
| `Ctrl + B` / `I` / `U` | Gras / Italique / Souligné *(G/I/S dans Office FR)* |

### Texte
| Raccourci | Action |
|---|---|
| `Ctrl + ←` / `→` | Sauter de mot en mot |
| `Ctrl + Shift + ←` / `→` | Sélectionner mot par mot |
| `Ctrl + Retour arrière` | Effacer le mot précédent |
| `Ctrl + Suppr` | Effacer le mot suivant |
| `Ctrl + Début` / `Fin` | Aller au début / à la fin du document |

### Fichiers et fenêtres
| Raccourci | Action |
|---|---|
| `Ctrl + N` | Nouvelle fenêtre / nouveau document |
| `Ctrl + O` | Ouvrir |
| `Ctrl + W` | Fermer l'onglet ou la fenêtre |
| `Ctrl + Shift + N` | Nouveau dossier (Explorateur) |
| `Ctrl + E` / `Ctrl + L` | Barre de recherche / d'adresse (Explorateur) |
| `Ctrl + clic` | Sélection multiple |
| `Ctrl + molette` | Zoom avant / arrière |
| `Ctrl + +` / `-` / `0` | Zoom avant / arrière / réinitialiser |

### Navigateur
| Raccourci | Action |
|---|---|
| `Ctrl + T` | Nouvel onglet |
| `Ctrl + Shift + T` | Rouvrir le dernier onglet fermé |
| `Ctrl + Tab` / `Ctrl + Shift + Tab` | Onglet suivant / précédent |
| `Ctrl + L` | Barre d'adresse |
| `Ctrl + D` | Ajouter aux favoris |
| `Ctrl + H` | Historique |
| `Ctrl + J` | Téléchargements |
| `Ctrl + Shift + N` / `P` | Navigation privée (Chrome/Edge / Firefox) |
| `Ctrl + F5` | Recharger sans le cache |

### Système
| Raccourci | Action |
|---|---|
| `Ctrl + Shift + Échap` | Gestionnaire des tâches |
| `Ctrl + Alt + Suppr` | Écran de sécurité (verrouiller, déconnecter…) |
| `Ctrl + Alt + Tab` | Sélecteur de fenêtres qui reste ouvert |
| `Ctrl + Échap` | Menu Démarrer |
